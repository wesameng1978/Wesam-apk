# WISSAM GYM — Chest Demo

نسخة Android أولية مستقلة من WISSAM GYM، مبنية بـ Kotlin وJetpack Compose Material 3. هذه النسخة موجودة داخل مجلد `wissam-gym/` ولا تستبدل مشروع Wissam File Master الموجود في جذر المستودع.

## الموجود في النسخة

- قسم CHEST فقط مع 18 تمريناً مستقلاً.
- صفحة تفاصيل لكل تمرين، مع الهدف، المعدات، التعليمات، نصائح التقنية والأخطاء الشائعة.
- بحث داخل مكتبة التمارين.
- مفضلة محفوظة محلياً.
- تتبع المجموعات والتكرارات والوزن.
- زر إكمال الجلسة وسجل محلي للجلسات.
- مؤقت راحة مدته 60 ثانية.
- تبديل عربي/إنجليزي مع RTL للعربية.
- تصميم داكن Premium بالأسود/الفحمي مع الأحمر.
- بنية قابلة للتوسع لاحقاً لأقسام الظهر والكتف والذراعين والرجلين والبطن.
- عمل دون اتصال بالإنترنت؛ البيانات الحالية محفوظة في SharedPreferences.

## حالة الرسوم المتحركة

لم يتم تضمين رسوم 3D حقيقية في هذه النسخة. شاشة كل تمرين تعرض مكاناً واضحاً بعنوان `Original animation asset pending` بدلاً من الادعاء بوجود حركة غير موجودة. إضافة شخصية رياضية موحدة وحركة مستمرة صحيحة ميكانيكياً لكل التمارين تحتاج أصول 3D قابلة للتحقق وخط أنابيب منفصل.

## البناء

```bash
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
export ANDROID_SDK_ROOT=/home/ubuntu/android-sdk
./gradlew assembleDebug bundleRelease
```

الناتج المحلي:

- `app/build/outputs/apk/debug/app-debug.apk`
- `app/build/outputs/bundle/release/app-release.aab`

الـ AAB في هذه النسخة غير موقّع بمفتاح نشر Play Store، ويحتاج توقيعاً قبل النشر العام.
